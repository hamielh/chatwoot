# Estrutura de Branches

## Fluxo

```
upstream/develop (oficial Chatwoot)
    ↓
develop (local sincronizado)
    ↓
staging (desenvolvimento/testes)
    ↓
main (produção estável)
```

## Branches

- **develop** - Espelho do upstream/develop (repo oficial)
- **staging** - Desenvolvimento e testes
- **main** - Produção 100% testada

## Remotes

- **origin** - hamielh/chatwoot (seu fork)
- **upstream** - chatwoot/chatwoot (oficial)
